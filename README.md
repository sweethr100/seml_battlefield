## 개요

마인크래프트 Java Edition 26.1.2용 배틀로얄 데이터팩입니다. 참가자를 월드 중앙 기준 넓은 지역에 흩뿌린 뒤, 시간이 지날수록 월드보더를 줄여 마지막 생존자 1명을 가리는 방식으로 진행됩니다.

## 설치

1. 이 폴더를 월드의 `datapacks` 폴더 안에 넣습니다.
2. 월드에 접속한 뒤 `/reload`를 실행합니다.
3. 채팅에 표시되는 `[클릭]` 리셋 버튼을 누르거나 아래 명령어를 실행합니다.

```mcfunction
/function seml:reset
```

## 운영 명령어

### 리셋

로비 구조물을 다시 설치하고, 참가자를 로비 좌표로 이동시키며, 보더와 상태를 초기화합니다.

```mcfunction
/function seml:reset
```

### 개인전 시작

```mcfunction
/function battleroyal:start
```

### 팀 배정

```mcfunction
/team join BLUE
/team join RED
```




## 게임 진행 흐름

1. `/function seml:reset`으로 로비를 준비합니다.
2. 참가자를 모은 뒤 시작 명령어를 실행합니다.
3. 보스바에 다음 자기장 축소까지 남은 시간이 표시됩니다.
4. 누군가 죽으면 해당 플레이어는 관전자 모드가 되고, 채팅으로 자신의 순위를 받습니다.
5. 생존자가 1명만 남으면 화면에 `게임 종료!`가 표시되고, 부제목으로 `1인자 : 플레이어명`이 출력됩니다.

## 시작 시 지급/적용

게임 시작 명령어를 실행하면 모든 참가자에게 아래 처리가 적용됩니다.

- 게임 모드: 서바이벌
- 인벤토리: 전체 초기화
- 경험치: 레벨과 포인트 모두 0으로 초기화
- 지급 아이템: 익힌 소고기 32개
- 효과: 무한 야간 투시
- 시작 위치: 월드 중앙 기준 최대 1500블럭 범위 안에 무작위 분산

## 게임 설정
- 사망 메시지 : 숨김
- 낙하 데미지 : 비활성화
- 월드보더 밖 데미지 : 적용
- 중간 합류자는 관전모드

## 자기장 시간표

게임이 시작되면 월드보더가 먼저 지름 3000블럭으로 설정되고, 참가자는 중앙 기준 넓은 지역에 흩어집니다. 이후 아래 순서대로 대기와 축소가 반복됩니다.

| 순서 | 진행 |
| --- | --- |
| 시작 | 월드보더를 지름 3000블럭으로 즉시 설정 |
| 1 | 18분 대기 |
| 2 | 10분 동안 지름 3000블럭에서 2000블럭으로 축소 |
| 3 | 15분 대기 |
| 4 | 10분 동안 지름 2000블럭에서 1000블럭으로 축소 |
| 5 | 12분 대기 |
| 6 | 10분 동안 지름 1000블럭에서 500블럭으로 축소 |
| 7 | 10분 대기 |
| 8 | 5분 동안 지름 500블럭에서 20블럭으로 축소 |
| 9 | 3분 대기 |
| 마지막 | 마지막 전장으로 전환하고 월드보더를 지름 31블럭으로 설정 |

마지막 전장에서는 생존자를 중앙의 좁은 전장으로 모으고, 관전자는 생존자 중 한 명을 관전하게 됩니다.
